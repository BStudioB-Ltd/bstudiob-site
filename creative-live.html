Tributary live presentation software

One room. Every screen in sync. Tributary is local-first desktop presentation and show-control software for church teams, meeting presenters and live performers. One host coordinates words, slides and cues with browser-based audience and performer screens over a trusted local network.

Product overview

One host for the room. Browser screens for the people in it.

Use the Controller to prepare and operate a service, meeting or performance. Performer and Audience devices receive the live presentation state over the same trusted venue network.

Church

Prepare a service running order, present song lyrics and browse the included King James Version (KJV) Bible by book, chapter and verse range.

Work

Import supported PDF or PowerPoint presentations, arrange meeting content and send the audience view to a room display. Tributary complements rather than replaces presentation authoring tools.

Artist

Plan a set with song arrangements, performer notes, role-specific monitors, show cues and backing-track controls.

Platforms, integrations and availability

Desktop host: Windows x64 and macOS (Apple silicon and Intel) beta builds exist, but installer versions and validation differ. The latest published beta, v1.6.2, has an Apple-silicon macOS disk image and a portable Windows x64 archive; Windows installed-runtime validation is still in progress. Intel Mac and Windows installer packages are available in the older v1.6.1 release. BStudioB provides access manually by invitation so it can confirm the appropriate build. Installers are unsigned and may trigger operating-system security warnings.

Other screens and tools: phones, tablets and computers can join as browser-based receiver screens on the trusted local network; they are not native iOS or Android apps. Projectors use the computer’s normal HDMI/DisplayPort display configuration. PDF and PowerPoint import are supported. OBS and Streamlabs remain separate video-production tools: Tributary does not natively switch cameras or control their scenes.

Access: This is invite-only beta software, not a public hosted service. There is no public self-service account, subscription checkout or automatic update/install flow; approved beta installers and updates are delivered manually.

Church

What it offers

Order songs and service moments, browse the included KJV by book and chapter, choose a verse range, and present the same live state to each receiver.

How it works

Build the running order on the host. Select a song or passage, then navigate from Controller or Performer while Audience screens stay synchronized over the local network.

Compared with a split setup

Instead of switching between separate lyric, scripture and display tools, keep those cues in one running order. Keep a spare manual backup for live services.

A live-performance workspace

Artist

What it offers

Chord-aware songbooks, set arrangements, musician-specific monitors, performer notes, show timing, backing-track transport and mapped pedal/MIDI/OSC controls.

How it works

Build and rehearse a set, assign performer roles, and navigate sections or tracks from Controller, Performer or mapped hardware. Audience output remains independently configurable.

Compared with a split setup

Bring charts, lyrics, cues and local backing playback into one session instead of juggling separate paper charts and lyric screens. Professional multichannel routing remains a separate audio workflow.
