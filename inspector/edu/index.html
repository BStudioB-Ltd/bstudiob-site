The learning path

From “what happened?”
to “here’s the evidence.”

Learners move from a guided story to a bounded sample task, then practise explaining an observation from the evidence.

01 / FOR LEARNERS · FOLLOW THE STORY

Story Mode

Join Mira’s Coffee Shop Recon. Trace sample café traffic through seven fictional beats, then notice how a simulated disconnect, rejoin and welcome page change the story.

Practise reading cause and consequence in context.

02 / FOR LEARNERS · TRY A BOUNDED TASK

Task Mode

Open Task 01: Information Gathering. Use three displayed sample commands to identify a sample user, label a fictional host and inspect sample interfaces. The page returns fixed sample output; no command executes.

Turn an observation into evidence you can explain.

03 / FOR INSTRUCTORS · DISCUSS THE EVIDENCE

Read the record

Use the visit-only evidence record to discuss what the learner observed, what changed and how a conclusion follows. Its entries are fixed sample text, not saved learner outcomes or assessment data.
